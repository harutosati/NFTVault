## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTVault.git`
2. `cd NFTVault`
3. Install in editable mode: `pip install -e .`

## Configuration

NFTVault is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
